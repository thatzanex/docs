## What this is

Jugendtreff is a Roblox social "hangout" experience: a forest clearing map with benches, a fountain, party minigames (musical chairs, spin-the-bottle, tic-tac-toe), a cosmetics/vanity progression loop (playtime-based titles, nametag styles), and a staff moderation stack (Cmdr, Adonis, custom rank-gated tools).

<Note>
  One module, `ServerScriptService.Data.SecretService` (and its sibling under `ServerScriptService.SecretService`), is intentionally **excluded** from this documentation set. It was not read, inspected, or summarized as part of this pass, per project instructions.
</Note>

## Server/Client split

The game follows a strict **server-authoritative** model:

- **`ServerScriptService`** — all game logic that can affect data, economy, or fairness. Nothing here is trusted to the client.
- **`ReplicatedStorage`** — shared modules, RemoteEvents/RemoteFunctions, and read-only client APIs.
- **`StarterPlayer`** (`StarterPlayerScripts` / `StarterCharacterScripts`) — client-side presentation: HUD, local lighting, sound playback, Cmdr console.
- **`StarterGui`** — screen GUIs (HUD, Notifications, Shop, Stuhltanz overlay, "TouchGrass" minigame UI).
- **`Workspace.Systems`** / **`Workspace.Objects`** — physical minigame rigs (bottles, chairs, tic-tac-toe board, teleport pads).

## Core design rules observed in the codebase

1. **Never trust the client.** Every purchase/unlock/equip flow goes `Client → RemoteEvent/RemoteFunction → Server`, and the server re-validates ownership before mutating data.
2. **Data lives in one place.** `DataApi` (server) and `ClientDataApi` (client, read-only) are the only sanctioned entry points into player data — no other script reads/writes ProfileStore directly.
3. **Collections are generic.** Titles, Overhead Styles, and Items all reuse the same `CollectionClass` (`Give` / `Take` / `Equip` / `Unequip` / `Has`) instead of bespoke per-category code.
4. **Staff permissions are rank-based**, sourced from a single Roblox group (`179209791`), with a shared rank→level table reused by both Cmdr hooks and title eligibility checks.
